# 입력 파일 폴더

어닝콜 대본 텍스트 파일을 이 폴더에 넣으세요.

## 파일명 규칙

```
{회사명}_{분기}.txt
```

예시:
- `unity_2025Q1.txt`
- `applovin_2025Q2.txt`
- `datadog_2025Q3.txt`

## 파일 준비 방법

1. IR 사이트 또는 Seeking Alpha 등에서 어닝콜 트랜스크립트 전문을 복사
2. 텍스트 편집기에 붙여넣고 `.txt` 파일로 저장
3. 파일명을 `{회사명}_{분기}.txt` 형식으로 지정
4. 이 폴더에 저장

## 여러 기업 동시 처리

파일을 여러 개 넣으면 병렬로 처리됩니다:

```
input/
  unity_2025Q1.txt
  applovin_2025Q1.txt
  datadog_2025Q1.txt
```

"어닝콜 분석 실행해줘" 한 마디로 3개 기업이 동시에 처리됩니다.

## 주의사항

- 파일명에 공백 없이 언더스코어(_) 사용
- 분기 형식: 2025Q1, 2025Q2, 2025Q3, 2025Q4
- 인코딩: UTF-8 권장
- 처리가 완료된 파일은 `processed/` 폴더로 이동하거나 그대로 두어도 됩니다 (재실행 시 기존 artifacts를 덮어씁니다)
