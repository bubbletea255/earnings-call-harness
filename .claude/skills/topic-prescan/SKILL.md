# Topic Pre-scan — Cross-QA 주제 연결 파악

## Overview

이 Skill은 earnings-topic-scanner Agent가 모든 번역 파일을 가볍게 훑어 Q&A 간 연결 관계를 파악하고 topic_map.md를 생성할 때 따르는 절차다.
2단계 요약 Agent들이 이 파일을 참조해 요약의 맥락을 풍부하게 만든다.
깊은 분석이 아니라 빠른 주제 파악이 목표다.

## Workflow

### 1단계: 번역 파일 수집

```
Glob: artifacts/{회사명}_{분기}/01_translation_*.md
```

파트 목록과 순서를 확인한다.

### 2단계: 각 파트의 주요 주제 파악

각 번역 파일을 읽고 2~3개의 핵심 주제를 간략히 파악한다.
- CEO: 전략 방향, 실적 하이라이트, 핵심 메시지
- CFO: 주요 수치 영역, 가이던스, 비용 구조
- Q&A: 각 질문자가 다룬 주제

### 3단계: Cross-QA 연결 식별

아래 패턴을 찾는다:
- **후속 질문**: QA-N에서 나온 주제가 QA-M에서 다시 언급됨
- **반복 주제**: 여러 Q&A에서 같은 주제가 반복 질문됨
- **꼬리 질문**: "앞서 언급한 X에 대해 더 구체적으로..."

### 4단계: topic_map.md 작성

출력 형식:

```md
# Topic Map: {회사명} {분기}
생성 일시: {날짜}

## 파트별 주요 주제

- CEO: {주제1}, {주제2}, {주제3}
- CFO: {주제1}, {주제2}
- QA1 ({질문자} / {소속}): {주제1}, {주제2}
- QA2 ({질문자} / {소속}): {주제1}
...

## Cross-QA 연결

| 연결 | 주제 | 메모 |
|---|---|---|
| QA1 → QA3 | 마진 구조 | QA1에서 제기된 gross margin 압박을 QA3에서 재질문 |
| QA2 → QA5 | 가이던스 | QA2의 full-year guidance에 대해 QA5에서 구체적 근거 요청 |

## 여러 파트에서 반복된 주제

| 주제 | 등장 파트 |
|---|---|
| AI/클라우드 수요 | CEO, QA1, QA3, QA4 |
| 마진 구조 | CFO, QA1, QA3 |
| 가이던스 신뢰도 | CFO, QA2, QA5 |
```

### 5단계: 파일 저장

출력 파일: `artifacts/{회사명}_{분기}/topic_map.md`

## 품질 기준

- 모든 번역 파일이 파트 목록에 포함되었는가
- Cross-QA 연결이 실제 텍스트 근거에 기반하는가
- 과도한 분석 없이 가볍게 작성되었는가 (각 항목 한 줄)
- 요약 Agent가 참조하기 쉬운 형식인가

## 예외 처리

- Q&A 간 명확한 연결이 없으면 Cross-QA 연결 섹션을 "연결 없음"으로 표시한다
- 번역 파일이 일부 누락된 경우 있는 파일만으로 진행하고 누락 파트를 메모로 표시한다
